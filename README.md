# Simple-Elgamal-Chat
Project done with Chris Perez as the final project in my Intro to Cryptography class at SUNY Potsdam.

# Explanation
This project was done in November to December 2025. The code is not pretty, but everything was implemented from scratch (except for AES) in Python. The communication approach and algorithms were implemented by me. Tests and planning were done by Chris and I. This program only works for computers on the same network, using their local device IP address.

The folder labeled "Project" contains all of the relevant information including it's README.
